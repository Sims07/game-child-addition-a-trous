# 🚀 L'Aventure des Maths — Portail de Jeux Éducatifs

Un portail web moderne, ludique et dynamique conçu pour réunir l'ensemble des jeux éducatifs de calcul mental et de mathématiques destinés aux enfants (niveau CE2).

---

## 🌟 Fonctionnalités

* 🎮 Accès centralisé : Un point d'entrée unique vers l'ensemble des jeux.
* 🎨 Design Pop & Inclusif : Une interface moderne inspirée du style papeterie / stickers avec des couleurs pimpantes, des ombres marquées et de la typographie arrondie.
* 📱 Totalement Responsive : Adapté aux écrans de tablettes, d'ordinateurs et de smartphones.
* ⚡ Ultra rapide & Léger : Page HTML/CSS pure sans dépendances lourdes ni frameworks.

---

## 🎮 Jeux disponibles

1. ⚡ Calcul Mental
   - Description : Exercices de calcul rapide et d'entraînements chronométrés.
   - Lien : https://sims07.github.io/game-child-calcul-mental/

2. 🐍 Math Serpent CE2
   - Description : Version éducative du jeu Snake pour réviser le programme de CE2.
   - Lien : https://sims07.github.io/game-child-math-serpent-ce2/

3. 🎯 Le Compte est Bon
   - Description : Enigmes mathématiques et combinaisons de nombres pour atteindre le chiffre cible.
   - Lien : https://sims07.github.io/game-child-compte-est-bon/

4. 📐 Géométrie CE2
   - Description : Figures planes, solides, vocabulaire (sommet, côté, angle droit) et exercices de tracé.
   - Lien : https://sims07.github.io/game-child-geometrie-droite/

5. 💡 Maths Flash CE2 — Le Club des Astuces
   - Description : Astuces de calcul mental (passage à la dizaine, +9, +8) avec mode pas à pas et défi rapide.
   - Lien : https://sims07.github.io/game-child-calcul-mental-astuce/

6. 🎃 Maths d'Halloween — Additions à Trous
   - Description : Additions à trous à 2 chiffres avec ardoise magique tactile, combo de bonbons et réglages de difficulté.
   - Lien : https://sims07.github.io/game-child-addition-a-trous/

## 🚀 Déploiement sur GitHub Pages

1. Allez dans les Settings de ce dépôt sur GitHub.
2. Cliquez sur l'onglet Pages dans le menu de gauche.
3. Dans Source, sélectionnez la branche main (ou master) et le dossier / (root).
4. Cliquez sur Save. Votre portail sera accessible en quelques instants !
